# Odin Recipes

A simple recipe website built as part of **The Odin Project** Foundations Course.

## About

This project demonstrates the fundamentals of HTML by creating a basic multi-page recipe website. It focuses on structuring web pages using semantic HTML elements and linking pages together.

## Features

- Homepage with links to recipes
- Three recipe pages:
  - Rendang
  - Nasi Goreng
  - Sate Ayam
- Images for each recipe
- Ingredients and cooking steps
- Basic navigation between pages

## Built With

- HTML5

## What I Learned

Through this project, I practiced:

- Creating HTML documents
- Using headings, paragraphs, lists, and images
- Creating links between pages
- Organizing a simple project structure
- Using Git and GitHub for version control

## Project Structure

```text
odin-recipes/
├── index.html
├── README.md
└── recipes/
    ├── rendang.html
    ├── nasi-goreng.html
    └── sate-ayam.html
```
